
# Lumincoin Finance 
- это удобное приложения для работы с личными финансами.
## О проекте
В рамках проекта реализовано полноценное CRUD-приложение (создание, чтение, обновление, удаление) для учета доходов и расходов с визуализацией данных.
Отслеживать финансовые потоки можно как в виде списка, так и с помощью наглядной диаграмммы.
Особое внимание уделено безопасности пользовательских данных: реализована система авторизации с ограниченным временем жизни токена (15 минут).
В приложении доступна регистрация нового пользователя, вход на свою страницу, работа с данными, изменение баланса, выход со страницы.

## Структура проекта: 
Проект состоит из двух основных частей:
- Backend: запуск через `cd backend` && `npm i` && `npm start`.
- Frontend: запуск через `cd frontend` && `npm i` && `npm run dev` (требуется предварительно запущенный сервер).

## Версии реализации: 
В репозитории представлены две ветки для демонстрации разных подходов к разработке:
- `main`: базовая реализация на чистом JavaScript.
- `stepTS`: улучшенная версия на TypeScript, демонстрирующая работу с типизацией, повышение надежности кода и устранение потенциальных ошибок на этапе компиляции.
